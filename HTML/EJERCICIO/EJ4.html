Aprende HTML es muy divertido

en este ejercicio vamos a repasar el concepto de estructura de un documento

El HTML es un lenguaje de marcado que constitute uno de los pilares de la web. Fue inventado por Tim Berners Lee en 1990 a partir se otro lenguaje denominado SGML y que servia para dotar de estructura documental a una informacion

El lenguaje de marcado es básicamente un idioma que se caracteriza por etiquetar el contenido de una página web. El HTML nos ayuda a conferir a los documentos web de contenido y estructura.
